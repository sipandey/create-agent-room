# Implementation Plan: Attested PR Description Skill (Story 9.9)

## Overview
Implement the canonical `describe-pr.md` procedural skill (`/describe_pr` and `/describe-pr`) in `create-agent-room`. This skill synthesizes rich, compliant pull request descriptions by combining architectural diff analysis, repository PR template conformance, execution attestation proofs generated by `create-agent-room pr-desc --verify`, and direct GitHub CLI synchronization.

---

## What We're NOT Doing
- We are NOT replacing the underlying `pr-desc` command in `lib/pr.js` (we are operationalizing it as an agent skill).
- We are NOT modifying remote PR descriptions without explicit human approval.
- We are NOT omitting verification proofs (PR descriptions must embed real test execution attestation).
- We are NOT introducing external npm dependencies.

---

## Phase 1: Author `describe-pr.md` Skill & Template
Implement the canonical skill document adhering to CAR's prompt standards, frontmatter requirements, and operational seatbelts.

- [x] **Phase 1.1**: Create `templates/.agent-room/skills/describe-pr.md` with:
  - YAML frontmatter: `name: describe-pr`, `description: "Synthesize comprehensive PR descriptions with deep architectural diff analysis, verified execution proofs, and GitHub CLI sync."`
  - Hard Gate: Never run `gh pr edit` without explicit user confirmation; must embed test attestation proof from `create-agent-room pr-desc --verify`.
  - Context Discovery: Discover PR number and branch via `gh pr view`, inspect repository PR template if available (`.github/pull_request_template.md`).
  - Architectural Diff Analysis: Analyze `gh pr diff` or `git diff origin/main...HEAD`. Group changes into User-Facing vs. Internal, highlight Breaking Changes and Migration requirements.
  - Test Attestation Integration: Run `node bin/cli.js pr-desc . --verify --output .agent-room/pr-description.md` (or `create-agent-room pr-desc . --verify --output .agent-room/pr-description.md`) to capture execution proof and compliance checklist.
  - Interactive Confirmation Gate: Present synthesized PR description to human and prompt: `"Shall I update the PR description on GitHub?"`.
  - GitHub PR Sync: Update remote PR using `gh pr edit <number> --body-file .agent-room/pr-description.md`.
- [x] **Phase 1.2**: Copy `templates/.agent-room/skills/describe-pr.md` to `.agent-room/skills/describe-pr.md` for dogfooding.
